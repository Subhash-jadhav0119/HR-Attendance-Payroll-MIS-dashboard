# 📊 HR Attendance & Payroll MIS Dashboard | Excel

## Project Overview

This project presents an interactive *HR Attendance & Payroll MIS Dashboard developed in Microsoft Excel* to monitor employee attendance, workforce availability, and payroll information.

The dashboard is designed to provide HR teams and managers with a clear, consolidated view of workforce and payroll measures. It can help users review attendance patterns, compare employee or department results, and track payroll totals for a selected reporting period.
